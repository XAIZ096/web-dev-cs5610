01 — Essential HTML Tags

10 most useful HTML elements

<div>

The generic block-level container. Used for grouping and layout.

<span>

Inline container for styling a piece of text without breaking flow.

<a>

Anchor tag — creates hyperlinks to pages, files, or page sections.

<p>

Paragraph text. The default block for readable body content.

<ul> / <ol>

Unordered and ordered lists. Used for navigation, steps, or items.

<img>

Embeds images. Always add alt text for accessibility and SEO.

<input>

Form input fields — text, email, checkbox, radio, and more.

<button>

Clickable button. More accessible than a div with an onClick.

<section>

Semantic grouping of related content with its own heading.

<header> / <footer>

Semantic landmarks for the top and bottom of a page or section.

02 — SEO Meta & Header Tags

These tags live inside <head> and are invisible on the page. This section shows the tags used for this site.

<title>

Most important SEO tag. Shown in the browser tab and as the clickable link in Google results. Should be under 60 characters with the primary keyword near the front.

<title>Web Dev Notes | HTML & CSS Fundamentals</title>

meta description

The summary snippet shown under a page link in search results. Does not directly affect ranking but strongly affects click-through rate. Aim for 150–160 characters.

<meta name="description" content="A practice project covering HTML structure, CSS box model, font sizing, and positioning" />

meta keywords

Once important, now largely ignored by Google. Still used by a few minor search engines. Low priority in modern SEO.

<meta name="keywords" content="HTML, CSS, web development, box model, positioning, SEO" />

viewport

Tells the browser how to scale the page on mobile. Required for responsive design. Google uses mobile-first indexing, so omitting this tag negatively affects ranking.

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

canonical

Prevents duplicate content penalties. If the same page is accessible at multiple URLs, canonical tells Google which one is the official version to index.

<link rel="canonical" href="https://yoursite.com/web-dev-notes" />

robots

Controls whether search engine crawlers index the page and follow its links. noindex is used on admin pages, thank-you pages, or content not meant to appear in search results.

<meta name="robots" content="index, follow" />

og:title

Open Graph Title tags control how the page title appears when shared on Facebook, LinkedIn, Slack, etc. Without them, platforms attempt to guess the title — usually inaccurately.

<meta property="og:title" content="Web Dev Notes | HTML & CSS Fundamentals" />

og:description

Open Graph Description tags control how the page description snippet appears when shared on Facebook, LinkedIn, Slack, etc. Without them, platforms attempt to guess the content summary — usually inaccurately.

<meta property="og:description" content="A hands-on HTML & CSS practice reference page." />

og:image

The thumbnail displayed when a page is shared on social media. The recommended size is 1200×630px. This tag significantly affects engagement on shared links.

<meta property="og:image" content="https://yoursite.com/preview.jpg" />

og:type

Declares the kind of content (website, article, video).

<meta property="og:type" content="website" />

og:url

Sets the canonical URL for the shared object — important for share-count aggregation.

<meta property="og:url" content="https://yoursite.com/" />

author

Identifies the creator of the page. Not used by Google for ranking, but useful for attribution and can appear in search results for article-type content.

<meta name="author" content="Aishwarya Rajmohan" />

charset

Tells the browser how to decode the text on the page. UTF-8 is the standard — it supports every language and emoji. Should be the first tag inside <head>.

<meta charset="UTF-8" />

lang

Set on the <html> tag itself, not a meta tag. Tells search engines and screen readers what language the page is written in. Important for accessibility and international SEO.

<html lang="en">

05 — Font Size Units

The same text rendered in 6 different units — a mix of absolute and relative sizes:

  • 12px Absolute The quick brown fox jumps over the lazy dog. Use px when pixel-perfect control is needed, like a fixed badge or icon label. Does not scale with user font preferences.
  • 1.5em Relative The quick brown fox jumps over the lazy dog. Use em for sizes relative to the parent element. Useful for components that should scale with their container's font size.
  • 1rem Relative The quick brown fox jumps over the lazy dog. Use rem for sizes relative to the root (html) font size. Preferred for body text — predictable and respects user browser settings.
  • 2.5rem Relative The quick brown fox jumps over the lazy dog. Use larger rem values for headings. Scales consistently across the site when the root font size changes.
  • 150% Relative The quick brown fox jumps over the lazy dog. Use % when the size should be a proportion of the parent's font size. Useful in fluid and responsive layouts.
  • 18pt Absolute The quick brown fox jumps over the lazy dog. Use pt for print stylesheets. 1pt = 1/72 inch. Avoid on screen — use px or rem instead.

06 — CSS Positioning

Four values for position, each behaves differently. The desk below shows them in context — each item represents a positioning type.

static

The default for every element. Flows in normal document order. top, left etc. have no effect. Use when the element needs no special placement.

relative

Stays in document flow but can be nudged with top/left/right/bottom relative to its original spot. The original space is still reserved. Use when shifting an element slightly or creating a containing block.

absolute

Removed from normal flow. Positioned relative to its nearest positioned ancestor. Use when placing tooltips, badges, or decorative elements at an exact spot.

fixed

Positioned relative to the viewport — stays on screen even when scrolling. Use for sticky navbars, floating buttons, or persistent footers. The footer on this page uses position: fixed.
